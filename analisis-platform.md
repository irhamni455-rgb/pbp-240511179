# Analisis Komparatif Platform: Spotify

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML5, CSS3, JavaScript (React) | C++, JavaScript, TypeScript (Chromium/Electron) | Kotlin / Java (Android), Swift / Objective-C (iOS) |
| **Arsitektur** | Klien berbasis browser (Single Page Application) | Aplikasi desktop lintas platform (berbasis CEF/Electron & pustaka native C++) | Aplikasi *native* seluler yang dioptimalkan untuk perangkat keras mobile |
| **Cara distribusi** | Melalui peramban web (*browser* modern tanpa instalasi) | Diunduh langsung dari situs resmi, Microsoft Store, atau Mac App Store | Diunduh melalui Google Play Store, Apple App Store, atau Amazon Appstore |
| **Keunggulan** | - Dapat diakses di mana saja tanpa instalasi aplikasi.<br>- Menghemat ruang penyimpanan lokal. | - Mendukung pintasan keyboard (*shortcuts*).<br>- Kualitas audio maksimal (hingga *Very High* / Lossless di masa mendatang).<br>- Kinerja lebih stabil untuk sesi panjang. | - Portabilitas tinggi (bisa didengarkan saat bepergian).<br>- Fitur *offline mode* (unduh lagu) yang optimal.<br>- Integrasi penuh dengan perangkat keras ponsel (notifikasi, kontrol *lockscreen*, Bluetooth). |
| **Keterbatasan** | - Bergantung penuh pada stabilitas peramban dan internet.<br>- Batasan kualitas audio pada beberapa *browser*.<br>- Pintasan keyboard terbatas. | - Memerlukan instalasi dan memakan penyimpanan lokal lebih besar.<br>- Penggunaan RAM cenderung lebih tinggi karena berbasis *framework* desktop. | - Layar lebih kecil untuk navigasi pustaka yang kompleks.<br>- Batasan manajemen memori sistem operasi seluler terhadap aplikasi latar belakang. |
| **Contoh aplikasi** | Spotify Web Player (`open.spotify.com`) | Spotify Desktop App (Windows / macOS) | Spotify Mobile App (Android / iOS) |
